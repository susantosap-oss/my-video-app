🚀 Memulai — Cara Kerja Aplikasi

        
Video Generator membantu kamu membuat video konten secara otomatis dari klip atau foto yang kamu upload. Ada dua mode penggunaan:

        

          

            
🤖 Full AI Mode

            
AI otomatis menentukan urutan klip, durasi trim, caption, warna, font, dan transisi berdasarkan deskripsi properti yang kamu tulis. Hasil lebih konsisten & profesional.

            
⚡ Tersedia untuk paket Basic ke atas

          

          

            
🎛️ Manual Mode

            
Kamu mengatur sendiri caption, warna teks, transisi, font, dan color grading. Cocok untuk kebutuhan yang lebih spesifik atau paket Trial.

            
✓ Tersedia untuk semua paket

          

        

        

          
📋 Alur Kerja

          
    
            
  1. Upload klip video atau foto
    2. 
            
  2. Tulis deskripsi konten (untuk AI) atau atur parameter manual
    3. 
            
  3. Isi data CTA — nama kontak & nomor WA (opsional)
    4. 
            
  4. Pilih BGM, resolusi, dan durasi target
    5. 
            
  5. Klik Render Video dan tunggu prosesnya
    6. 
            
  6. Unduh hasil video MP4
    7. 
          

        

        

          
💡 Tips: Untuk hasil terbaik, gunakan klip dengan pencahayaan baik, durasi 5–15 detik per klip, dan tulis deskripsi yang detail untuk mode Full AI.

        

      


      
      

        
📁 Upload Media

        

          

            
🎬 Tab Video — Upload Klip Video

            
    
              
  • Format didukung: MP4, MOV, AVI, MKV
    • 
              
  • Upload satu atau lebih klip — sistem akan memilih segmen terbaik secara otomatis
    • 
              
  • Rekomendasi: klip 5–30 detik per file, resolusi minimal 720p
    • 
              
  • Drag & drop file langsung ke area upload, atau klik untuk browse
    • 
              
  • Klip yang sudah diupload tampil sebagai chip — klik ✕ untuk hapus
    • 
            

          

          

            
🖼️ Tab Photo — Slideshow Foto

            
    
              
  • Format didukung: JPG, PNG, WEBP
    • 
              
  • Upload banyak foto — akan dijadikan slideshow otomatis
    • 
              
  • Durasi per slide menyesuaikan total durasi target
    • 
            

          

          

            
🏷️ Logo & 🎵 BGM (Opsional)

            
    
              
  • Logo: format PNG dengan transparansi (RGBA). Ditampilkan di pojok kiri bawah pada setiap frame caption
    • 
              
  • BGM: format MP3 atau WAV. Akan di-loop atau dipotong sesuai durasi video. Volume BGM bisa diatur di bagian Render
    • 
            

          

          

            
💡 Tips Upload: Pastikan nama file tidak mengandung karakter khusus. Upload klip terbaik dahulu — jika menggunakan Full AI, sistem akan memilih urutan berdasarkan kualitas.

          

        

      


      
      

        
🤖 Full AI Mode

        
Full AI Mode menggunakan kecerdasan buatan untuk menghasilkan spesifikasi render lengkap secara otomatis — mulai dari urutan klip, trim, caption, hingga color grading.

        

          

            
✏️ Deskripsi Konten

            
Tulis deskripsi detail tentang isi video kamu. Semakin lengkap, semakin relevan hasil AI-nya.

            

              
Contoh deskripsi bagus:

              
"Rumah 2 lantai di Serpong, 4 kamar tidur, kolam renang, taman luas. Eksterior modern minimalis dengan material batu alam. Interior mewah dengan kitchen set built-in dan ruang keluarga luas."

            

          

          

            
🎨 Instruksi Gaya (Opsional)

            
Beri arahan tambahan ke AI tentang tone dan style video yang diinginkan.

            

              
Contoh:

              
"Video properti premium, hook kuat dari eksterior terbaik, interior di tengah, tutup dengan view lokasi. Tone hangat dan aspirasional untuk TikTok."

            

          

          

            
⚡ API Key — Cara Mendapatkan

            
Jika server belum dikonfigurasi dengan API key, kamu bisa memasukkan key milikmu sendiri. Key tidak disimpan di server.


            
            

              

                🔵
                
Google Gemini (Rekomendasi — Free Tier Tersedia)

              

              
    
                
  1. Buka aistudio.google.com
    2. 
                
  2. Login dengan akun Google kamu
    3. 
                
  3. Klik Get API Key → Create API Key
    4. 
                
  4. Pilih project Google Cloud (atau buat baru)
    5. 
                
  5. Copy API key yang muncul — formatnya dimulai dengan AIza...
    6. 
                
  6. Paste di field API Key dan pilih provider Gemini
    7. 
              

              

                
✓ Free tier: 1.500 request/hari, 1 juta token/menit — cukup untuk penggunaan normal

                
Model yang digunakan: Gemini 2.0 Flash

              

            


            
            

              

                🟠
                
Anthropic Claude (Berbayar — Pay as You Go)

              

              
    
                
  1. Buka console.anthropic.com
    2. 
                
  2. Daftar akun atau login
    3. 
                
  3. Masuk ke menu API Keys di sidebar
    4. 
                
  4. Klik Create Key — beri nama key (contoh: "VideoGen")
    5. 
                
  5. Copy API key — formatnya dimulai dengan sk-ant-...
    6. 
                
  6. Tambahkan saldo di menu Billing (minimal $5)
    7. 
                
  7. Paste di field API Key dan pilih provider Anthropic
    8. 
              

              

                
⚠ Berbayar per token — estimasi ~$0.001–0.003 per video spec

                
Model yang digunakan: Claude Haiku (tercepat & termurah)

              

            


            

              
💡 Rekomendasi: Mulai dengan Google Gemini — gratis dan sudah cukup untuk kebutuhan sehari-hari. Gunakan Anthropic jika ingin hasil caption yang lebih natural dalam Bahasa Indonesia.

            

          

          

            
📊 Hasil AI Spec

            
Setelah AI selesai, kamu bisa melihat preview spesifikasi yang dihasilkan: urutan klip, caption, warna, font, transisi, dan color grade. Spec ini langsung dipakai saat render.

          

          

            
💡 Tips Full AI: Upload minimal 3 klip berbeda untuk hasil terbaik. Gunakan deskripsi dalam Bahasa Indonesia — AI sudah dioptimasi untuk konten properti Indonesia.

          

        

      


      
      

        
🎛️ Pengaturan Manual

        

          

            
💬 Caption & Teks

            
    
              
  • Deskripsi Konten: Teks ini akan otomatis dipecah menjadi beberapa caption menggunakan NLP
    • 
              
  • Jumlah Caption: Berapa banyak caption yang ingin ditampilkan (1–5). Caption pertama otomatis lebih besar sebagai hook
    • 
              
  • Warna Detail: Pilih warna untuk caption ke-2 dan seterusnya. Caption pertama (hook) selalu Gold
    • 
              
  • Posisi Teks: Center, Left, atau Right
    • 
            

          

          

            
🔤 Font

            
    
              
  • Pilih dari font yang tersedia di sistem
    • 
              
  • Font bold/impact lebih cocok untuk konten properti premium
    • 
              
  • Jika tidak dipilih, sistem menggunakan font default
    • 
            

          

          

            
✨ Transisi

            
    
              
  • Crossfade: Perpindahan halus antar klip — cocok untuk properti premium
    • 
              
  • Fade to Black: Fade hitam antar klip — kesan sinematik
    • 
              
  • Tanpa Transisi: Cut langsung — lebih dinamis
    • 
              
  • Durasi: 0.2–1.5 detik, rekomendasi 0.4 detik
    • 
            

          

          

            
🎨 Color Grading

            
    
              
  • Aktifkan untuk mempercantik warna video secara otomatis
    • 
              
  • Brightness: Kecerahan frame (1.0 = normal)
    • 
              
  • Contrast: Ketajaman gelap-terang
    • 
              
  • Saturation: Kejenuhan warna
    • 
              
  • Sharpness: Ketajaman gambar
    • 
              
  • Rekomendasi properti premium: semua nilai sekitar 1.05–1.15
    • 
            

          

        

      


      
      

        
⚙️ Pengaturan Render

        

          

            
📞 CTA (Call to Action)

            
    
              
  • Label: Teks label sebelum nama (contoh: "Hubungi :")
    • 
              
  • Nama: Nama agen atau perusahaan — tampil dalam warna Gold
    • 
              
  • Nomor WA: Nomor WhatsApp — tampil di akhir video
    • 
              
  • Durasi CTA: Berapa detik CTA tampil di akhir video (rekomendasi 3–5 detik)
    • 
              
  • CTA bersifat opsional — kosongkan jika tidak diperlukan
    • 
            

          

          

            
🎵 Audio

            
    
              
  • Volume BGM: Volume musik latar (0 = mute, 1 = full). Rekomendasi 0.3–0.5
    • 
              
  • Volume Original: Volume audio asli dari klip video. Rekomendasi 0.7–0.9
    • 
              
  • Jika tidak upload BGM, hanya audio original yang digunakan
    • 
            

          

          

            
📐 Resolusi & Durasi

            
    
              
  • Resolusi: Output selalu format 9:16 portrait (vertikal) untuk TikTok & Reels
    • 
              
  • 360p = preview cepat  |  720p = standar  |  1080p = kualitas tinggi
    • 
              
  • Durasi Target: Total durasi video output yang diinginkan (dalam detik)
    • 
              
  • Sistem akan memotong atau menyesuaikan klip secara otomatis agar sesuai durasi
    • 
            

          

          

            
⏱️ Estimasi Waktu Render

            

              

                
Video 30 detik @ 720p~2–4 menit

                
Video 60 detik @ 720p~4–8 menit

                
Video 30 detik @ 1080p~5–10 menit

              

            

          

          

            
💡 Tips Render: Untuk review cepat gunakan 360p dulu, lalu render ulang di 1080p untuk hasil final. Jangan tutup browser saat render sedang berjalan.

          

        

      


      
      

        
⬇️ Unduh & Setelah Render

        

          

            
📊 Progress Render

            
    
              
  • Progress bar akan muncul otomatis setelah klik Render Video
    • 
              
  • Status akan diperbarui setiap beberapa detik: Loading clips → Pass 1 → Pass 2 → Selesai
    • 
              
  • Jika terjadi error, pesan error akan ditampilkan di bawah progress bar
    • 
            

          

          

            
⬇️ Download Video

            
    
              
  • Tombol ⬇️ Download Video muncul otomatis saat render selesai
    • 
              
  • Format output: MP4 (H.264 + AAC) — kompatibel dengan semua platform
    • 
              
  • Nama file: video_generator_[id].mp4
    • 
            

          

          

            
🔄 Render Ulang

            
    
              
  • Klik + New di navbar untuk memulai sesi baru dengan file baru
    • 
              
  • File upload dari sesi sebelumnya tidak tersimpan — perlu upload ulang
    • 
              
  • Kuota video dihitung per download, bukan per render
    • 
            

          

          

            
📱 Upload ke Platform

            
    
              
  • Video sudah dalam format 9:16 vertikal — langsung siap upload ke TikTok, Instagram Reels, YouTube Shorts
    • 
              
  • Resolusi 1080p direkomendasikan untuk kualitas terbaik di platform
    • 
              
  • Tambahkan caption / hashtag platform secara manual setelah upload
    • 
            

          

          

            
✅ Checklist Sebelum Publish

            
    
              
  • Tonton video dari awal sampai akhir
    • 
              
  • Pastikan CTA (nama & nomor WA) sudah benar
    • 
              
  • Cek audio — balance BGM dan suara asli
    • 
              
  • Pastikan caption tidak terpotong di frame
    •
